# Senior UI/UX Standards

## Product-first design

Start from the user's task, context, decisions and recovery needs. Style after the flow is correct.

## Avoid generic AI-slop patterns

Do not default to:

- giant decorative gradients;
- excessive glassmorphism;
- arbitrary cards for every section;
- oversized hero copy inside operational applications;
- meaningless charts/metrics;
- random icon decoration;
- excessive rounded containers and unused whitespace.

Use the existing product/design system when available.

## Required interaction states

Consider:

- loading;
- empty/first-use;
- success;
- validation error;
- permission denied;
- partial failure;
- fatal error;
- disabled/read-only;
- retry/offline when relevant.

## Accessibility baseline

Use semantic HTML/native controls where practical, labels, keyboard operation, visible focus, adequate contrast, understandable error messaging, non-color-only status and accessible overlays.

## Responsive behavior

Design the layout transition intentionally. Do not merely shrink the desktop interface.

## Enterprise/admin interfaces

Use tables, filters, compact forms and dense layouts when they improve scanning and task completion. Production quality does not require excessive whitespace.
