# Cybersecurity Incident Response

## Lifecycle

```text
prepare -> detect -> triage -> contain -> investigate
 -> eradicate -> recover -> communicate -> learn
```

## Severity

Base severity on business/service/data impact, scope, attacker persistence, exploitability and regulatory/customer implications—not only CVSS.

## First-response priorities

1. Safety and service/data protection.
2. Preserve evidence/time context.
3. Stop ongoing unauthorized access or destructive activity.
4. Establish incident commander and communication channel.
5. Identify affected identities/systems/data/tenants.
6. Rotate/revoke compromised credentials as appropriate.
7. Invoke privacy/legal/customer obligations promptly.
8. Recover from known-good state and verify integrity.

## Post-incident

Document timeline, root causes/contributing factors, what detection failed/succeeded, corrective actions, owners and effectiveness checks. Avoid blame-oriented postmortems that discourage reporting.
