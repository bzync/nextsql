# Data Subject / Consumer Rights Request Runbook

1. Intake request and jurisdiction/rights requested.
2. Authenticate/verify requester proportionately.
3. Establish scope and deadlines from current law.
4. Search authoritative systems and downstream processors.
5. Review exceptions/legal holds/third-party rights.
6. Approve decision with recorded rationale.
7. Execute access/export/correction/deletion/objection/restriction/opt-out as applicable.
8. Propagate to relevant downstream systems/vendors.
9. Verify execution.
10. Respond through the approved channel.
11. Retain minimal compliance evidence.

Never expose another person's data while fulfilling an access request.
