# Audit and Evidence Rules

## Auditor-friendly evidence package

For each requirement/control area prepare:

```text
owner
policy/process
implementation location
sample evidence
measurement/review cadence
exceptions
related risks
last internal verification
```

## Do not fabricate

If evidence does not exist, record a gap. Never generate a backdated record, fake meeting minutes, fake risk acceptance, fake training evidence, or claim a control was operating before it actually was.

## Sampling

Use representative operational samples across time where possible rather than one newly-created example immediately before an audit.

## Corrective actions

A finding closes only after:

```text
root cause
 -> corrective action
 -> owner/deadline
 -> implementation
 -> effectiveness verification
```
