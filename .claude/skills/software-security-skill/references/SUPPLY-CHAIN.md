# Software Supply Chain

## Inventory

Track material:

- source repositories;
- build systems/runners;
- package registries;
- direct/transitive dependencies;
- base images;
- generated artifacts;
- deployment identities;
- signing/provenance metadata when used.

## Threats

- compromised maintainer/package;
- dependency confusion/typosquatting;
- malicious install scripts;
- poisoned CI runner/cache;
- stolen registry/release credentials;
- mutable/untrusted base images;
- artifact replacement after testing;
- unreviewed autogenerated code.

## Controls

Use protected branches/reviews, least-privilege CI identities, pinned trusted sources, dependency update review, secret scanning, isolated builds, artifact integrity/provenance and controlled promotion according to risk.
