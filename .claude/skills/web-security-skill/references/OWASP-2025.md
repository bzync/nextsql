# OWASP Reference Snapshot

## OWASP Top 10:2025

Current official awareness categories at the snapshot include themes such as broken access control, security misconfiguration, software supply-chain failures, cryptographic failures, injection, insecure design, authentication failures, software/data integrity failures, security logging/alerting failures, and exceptional-condition handling.

Use the official OWASP release for exact category wording/details and future updates.

## ASVS 5.0.0

OWASP identifies ASVS 5.0.0 as the latest stable release at this snapshot. Use ASVS requirements as a structured basis for application security requirements/verification, but select rigor based on risk.

## WSTG

Use the stable WSTG for reproducible testing references. The "latest" branch may contain in-development material.

## API Security

OWASP API Security Top 10:2023 remains the official stable API Top 10 found at this snapshot. Authorization, resource consumption, SSRF, inventory and unsafe third-party API consumption deserve explicit API review.
